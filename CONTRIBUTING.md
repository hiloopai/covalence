# Contributing

Covalence is pre-alpha: APIs may change without notice.

- **Setup**: [README.md](README.md#getting-started) covers the Nix shell and the
  `glu` commands. `./bin/glu ci` must pass before a pull request is reviewed.
- **Pull requests**: small and focused, each saying what changes and why. Add
  tests for behaviour, not for re-exports.
- **Docs**: every public item is documented; [AGENTS.md](AGENTS.md) lists the
  rules (one-line summaries, plain words, claims checked against the code).
- **Security issues**: see [SECURITY.md](SECURITY.md); do not open a public
  issue.
