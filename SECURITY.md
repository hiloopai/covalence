# Security

Report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/hiloopai/covalence/security/advisories/new),
not in a public issue.

- Include what is affected (crate or Python package, version), how to
  reproduce it, and what an attacker gains.
- We reply in the advisory, and credit reporters in it unless asked not to.
- Covalence is pre-alpha: fixes go into the next release, and only the latest
  release is supported.
