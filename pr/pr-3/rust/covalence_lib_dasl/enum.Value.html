Enum Value 

Source 
pub enum Value {
    Null,
    Bool(bool),
    Integer(i64),
    Bytes(Bytes),
    String(String),
    List(Vec<Value>),
    Map(BTreeMap<String, Value>),
    Link(Cid<Bdasl>),
}
Expand description

A DASL value. There are no floats.

Dropping a hand-built value nested far deeper than MAX_DEPTH can overflow the stack. Decoded values are always within the limit.

Variants§

§

Null

null.

§

Bool(bool)

true or false.

§

Integer(i64)

An integer. DRISL allows -2^64 to 2^64 - 1; Value::decode rejects integers outside i64.

§

Bytes(Bytes)

A byte string.

§

String(String)

A UTF-8 string.

§

List(Vec<Value>)

A list of values.

§

Map(BTreeMap<String, Value>)

A map with string keys. Encoding writes keys in DRISL order: shorter keys first, then bytewise.

§

Link(Cid<Bdasl>)

A link to other data, by its DASL CID.
