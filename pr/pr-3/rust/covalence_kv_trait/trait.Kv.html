Expand description

A store of byte values by byte-string key, sync and async.

A store rejects keys it cannot hold with an error. Sync and async methods may see different data (sync might read only a local cache). Do not call the sync methods on an async runtime thread: they may block.

fn size(&self, key: &[u8]) -> Result<Option<u64>, Error>

The size in bytes of the value under key, or None if missing. The length of Kv::get by default.

Source

fn get_range( &self, key: &[u8], start: u64, len: u64, ) -> Result<Option<Bytes>, Error>

Up to len bytes under key from start, or None if missing. Slices Kv::get by default.

  • Fewer bytes at the end, and empty bytes at or past it.
  • Range ends beyond u64::MAX are clipped; replies never exceed len.
Source

fn put_from( &self, key: &[u8], reader: &mut dyn Read, len: u64, ) -> Result<(), Error>

Store the next len bytes of reader under key, replacing any previous value. Reads no further; fails with Error::Io if reader fails or ends early, and then stores nothing. Reads them into memory and calls Kv::put by default.

Source

fn put_new(&self, _key: &[u8], _value: Bytes) -> Result<bool, Error>

Atomically store value under key only if the key holds no value, and return whether it stored.

Never replaces a value, including when writers race. The default returns Error::Unsupported without reading or writing.

Source

fn put_new_from( &self, _key: &[u8], _reader: &mut dyn Read, _len: u64, ) -> Result<bool, Error>

As Kv::put_from, but atomically store only if the key holds no value, and return whether it stored.

Never replaces a value, including when writers race. When the key holds one, reader may have been read or not. The default returns Error::Unsupported without reading or writing.

Source

fn get_to( &self, key: &[u8], writer: &mut dyn Write, ) -> Result<Option<u64>, Error>

Write the value under key to writer and return its length, or None, writing nothing, if missing. Fails with Error::Io if writer fails; after any failure writer may hold part of the value. Writes Kv::get by default.

Source
