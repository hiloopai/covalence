fn put_fact(&self, fact: Fact<K>) -> Result<K, Error>
where K: Claim,

Store fact’s bytes and return the key Put::put would, which has the same multihash as the fact’s claim when the store keys by the claim’s hash. The claim already holds, so a store may skip hashing. Put::put by default.
