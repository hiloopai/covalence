Expand description

A store of bytes by CID, sync and async.

Sync and async methods may see different data (sync might read only a local cache), but get_fact and aget_fact are correct either way. Do not call the sync methods on an async runtime thread: they may block.

Provided Methods§

Source

fn has(&self, key: &Cid) -> Result<bool, Error>

Whether the store holds bytes for key, unchecked, as Get::get_unchecked would find them. Reads them by default; stores override it to avoid that.

Source

fn missing(&self, keys: &[Cid]) -> Result<Vec<Cid>, Error>

Those of keys that Cas::has says the store lacks, in order.

Source

fn info(&self) -> Result<Value, Error>

A DASL value describing the store, for debugging: null or a map. null by default; an error if the store cannot answer.

Source

fn stats(&self) -> Result<Value, Error>

A DASL value of whatever the store counts, for debugging: null or a map. null by default; an error if the store cannot answer.

Source

fn put_from( &self, cid: Blake3, reader: &mut dyn Read, len: u64, ) -> Result<Cid, Error>

Store the next len bytes of reader, whose raw BLAKE3 CID is cid, and return the key Put::put_fact would. Reads no further; stores nothing and fails with Error::Check if the bytes have another CID, or with Error::Io if reader fails or ends early. Reads them into memory by default; stores that can stream override it.

Source

fn get_to( &self, key: &Cid, writer: &mut dyn Write, ) -> Result<Option<u64>, Error>

Write the bytes under key to writer, checked as GetExt::get_fact checks them, and return their length, or None, writing nothing, if missing. Fails with Error::Check if they do not match key, or with Error::Io if writer fails; after a failure writer may hold unchecked bytes, so discard them. Writes GetExt::get_fact by default; stores that can stream override it.

This store as an Arc<dyn Cas>: wrapped in a new Arc, except that an Arc<dyn Cas> returns itself.
