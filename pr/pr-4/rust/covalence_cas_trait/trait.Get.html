Required Methods§

Source

fn get_unchecked(&self, key: &K) -> Result<Option<Bytes>, Error>

The bytes under key, or None if missing. Not checked.

Provided Methods§

Source

fn size_unchecked(&self, key: &K) -> Result<Option<u64>, Error>

The size in bytes of the value under key, or None if missing. Not checked. The length of Get::get_unchecked by default.

Source

fn get_range_unchecked( &self, key: &K, start: u64, len: u64, ) -> Result<Option<Bytes>, Error>

Up to len bytes under key from start, or None if missing. Not checked. Slices Get::get_unchecked by default.

  • Fewer bytes at the end, and empty bytes at or past it.
  • Range ends beyond u64::MAX are clipped; replies never exceed len.
Source

fn get(&self, key: &K) -> Result<Option<Bytes>, Error>

The bytes under key, as the store vouches for them. Get::get_unchecked by default.

Source

fn size(&self, key: &K) -> Result<Option<u64>, Error>

The size under key, as the store vouches for it. Get::size_unchecked by default.

Source

fn get_range( &self, key: &K, start: u64, len: u64, ) -> Result<Option<Bytes>, Error>

A range under key, as the store vouches for it. Get::get_range_unchecked by default.

Source

fn get_fact_unchecked(&self, key: &K) -> Result<Option<Fact<K>>, Error>

A fact the store holds for key, perhaps for another key. Hashes Get::get_unchecked by default.
