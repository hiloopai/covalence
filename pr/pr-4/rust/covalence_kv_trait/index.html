The key-value store trait.

A key-value (KV) store maps byte-string keys to byte values, and a put replaces any earlier value. Kv is the trait every store implements.

  • Sync methods get, put and exists, and async twins named as in Python: the sync name prefixed with a, so aget, aput and aexists.
  • Kv is object safe: every method returns the shared Error, and async ones a boxed KvFuture. Hold a store as Arc<dyn Kv> (or take &dyn Kv) rather than being generic; Kv::into_dyn makes one.
  • Kv::size and Kv::get_range fetch the whole value and measure or slice it by default; stores with native ranges override them.
  • Kv::put_from and Kv::get_to move a value between the store and a reader or writer. By default they hold it in memory; stores that can stream override them. They have no async twins: readers and writers block.
  • Stores live in their own crates, such as covalence-kv-memory and covalence-kv-s3.

A store needs only get, put, aget and aput; the defaults supply the rest:

use std::{collections::BTreeMap, sync::RwLock};

use covalence_kv_trait::{Error, Kv, KvFuture, ready};
use covalence_lib_data::Bytes;

#[derive(Default)]
struct Map(RwLock<BTreeMap<Vec<u8>, Bytes>>);

impl Kv for Map {
    fn get(&self, key: &[u8]) -> Result<Option<Bytes>, Error> {
        Ok(self.0.read().unwrap().get(key).cloned())
    }
    fn put(&self, key: &[u8], value: Bytes) -> Result<(), Error> {
        self.0.write().unwrap().insert(key.to_vec(), value);
        Ok(())
    }
    fn aget<'a>(&'a self, key: &'a [u8]) -> KvFuture<'a, Option<Bytes>> {
        ready(self.get(key))
    }
    fn aput<'a>(&'a self, key: &'a [u8], value: Bytes) -> KvFuture<'a, ()> {
        ready(self.put(key, value))
    }
}

let store = Map::default().into_dyn();
store.put(b"greeting", "hello".into())?;
assert_eq!(store.size(b"greeting")?, Some(5));
assert_eq!(store.get_range(b"greeting", 1, 3)?.unwrap(), "ell");
// Ranges stop at the end of the value; a missing key is `None`.
assert_eq!(store.get_range(b"greeting", 3, 10)?.unwrap(), "lo");
assert_eq!(store.get_range(b"greeting", 9, 1)?.unwrap(), "");
assert_eq!(store.get_range(b"missing", 0, 1)?, None);
assert!(!store.exists(b"missing")?);
